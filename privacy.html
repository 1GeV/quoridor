Privacy & data

Updated November 26, 2026.

Built-in AI runs on your device. External AI and online rooms are optional. This application has no accounts, advertising, analytics SDK, payment system or project-operated data server. Hosting and connection providers still process network data.

What stays in your browser

DataPurpose and retention
Theme, engines, game preferencesLocal storage, until you clear it.
Saved game moves and engine labelsLocal storage, up to 80 saved games. Saving can be switched off; existing games can be deleted.
Endpoint URL, API format and model settingsLocal storage, until cleared.
API keysTab session storage by default. Selecting “Remember key” also stores the key unencrypted in local storage until cleared.
AI conversations and decision cachePage memory only, lost on reload or closing the page. Clear a conversation using its button.
Built-in AI models and runtimeVerified public binaries in browser cache, reused across visits. They contain no API keys or conversation data. Remove them with “Clear this app's local data” or your browser's site-data controls. The browser may evict cached files.

Browser storage is not a secure vault. People, extensions or scripts with access to this browser or origin may access it. Downloads, exported games and backups remain wherever you save them. The application does not set advertising or tracking cookies.

Hosting and built-in AI

The browser requests page files, runtime and model weights from this site's host. Built-in AI inference does not send your moves to an AI service. A service worker adds browser isolation headers to this project's own files to enable CPU threads; it does not store game data or relay external AI requests. When hosted on GitHub Pages, GitHub logs visitors' IP addresses for security; its retention and rights procedures are governed by GitHub's privacy statement. Other hosts have their own policies.

Before connecting an external AI

External AI is disabled until you select it and configure a provider. Permission for automatic move requests is separately unchecked by default; without opting in, that AI seat waits and the page prompts you to enable permission. Enable “Allow automatic AI move requests” and select “Save & apply” to permit requests on its turns. Saving may start a provider request if that seat is due to move; paused AI-vs-AI games also require pressing Play. “Test” and sending an AI chat question each send an explicit live provider request, independently of automatic move permission. Local play remains available without a provider or key.

Requests go directly from your browser to the endpoint you enter. That endpoint receives your API key in an authentication header, model name, any selected reasoning effort and network metadata such as your IP address. No project relay is involved. Remote endpoints require HTTPS; plain HTTP is allowed only for a local loopback service.

For a move, the endpoint receives the rules, pawn coordinates, walls and reserves, side to move, move count, up to 12 recent moves and legal actions. If you enable board images and the model requests one, it also receives an image of the game board. This does not access your camera or take a screenshot of your desktop.

Chat and automatic moves send the current board and can include up to 12 completed chat exchanges and 12 prior AI moves for that seat, with their board snapshots and optional commentary. Messages you send in chat may therefore be sent again when the AI plays. This history stays in page memory between requests. Clearing the conversation, starting another game or changing the endpoint, model, API format or key clears the affected history. Responses calls request store: false. The provider may retain inputs through logging or prompt caching under its own policy.

The provider may charge, retain input or process data in another country. Review its terms, privacy policy, geographic availability and age restrictions before connecting. Do not submit personal or confidential information in AI chat. Clearing this app cannot delete data already received by the provider.

Online rooms

Creating or joining a room contacts the public PeerJS signalling service and WebRTC connection services such as STUN and, when available, TURN. They may process IP addresses, peer identifiers, room codes and connection metadata under their policies. The current PeerJS runtime may use relay services when a direct connection cannot be made.

The two players exchange game actions and synchronization messages over a WebRTC data channel. The opponent may learn your IP address and can record the game. A room code is an invitation, not verified identity or a password. Share it with a trusted opponent. Leaving room mode closes this app's connection; it does not erase the opponent's copy. There is no player-to-player text chat, public lobby, message board or player profile.

See PeerJS for the signalling service. We do not control its availability or retention practices and do not claim that it collects no data.

Your controls and deletion

Use “Forget this API key”, “Clear this AI conversation”, the saved-game delete controls, or “Clear this app's local data” in the game's footer. The last option deletes this app's preferences, saved games, endpoint settings and tab keys, then reloads. It does not clear unrelated applications, downloaded files, other open tabs' memory, provider logs or hosting logs. Browser storage is scoped to the origin; copies using the same keys on the same origin may share it.

The project provides no account or server-side archive of your games, keys or AI conversations for its maintainers to look up. Use the controls above to remove the application's browser data. For data already sent to a host or AI provider, use that provider's privacy procedures. Forgetting a key does not revoke it: revoke exposed keys at the provider.

Age and third-party services

The app does not ask for names, birth dates, identity documents, precise location or contact details, and does not verify a player's age. External AI providers may set their own age limits and parental-consent requirements. Review those rules before connecting; minors should involve a parent or guardian.
